## Staves

When creating an extra stave for a part (to display hits, or one-off notation):

- **Put the staff under the same instrument** in Layout and define 
  the staff by right clicking and set staff/part properties.

- You can set the number of lines, hide clefs, time signature, and key signature
 (in Advanced style properties).

***It has to be done on every part***.

### Hits Staff

in Advanced style properties

- Uncheck `Show clef`
- Uncheck `Show time signature`
- Uncheck `Show key signature`
- Lines: 1, Line distance: 0

This allows rhytmic notation on a single line staff

## Swing

When loading a style file, *the swing feel amount is loaded with it.*
 I always update the style to match the current format, which overwrites the 
 swing setting. A **text element** with swing amount set will override the loaded style, 
 so that ***should be in every score for playback consistency***. Make invisible.
